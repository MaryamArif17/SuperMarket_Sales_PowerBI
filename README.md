# Supermarket Sales Dashboard

## About the Project

This project is a Power BI dashboard created to analyse supermarket sales performance across different product categories, cities, products, and time periods.

The dashboard was created as a practice project to develop fundamental Power BI data visualisation and analytical skills.

## Dashboard Analysis

The dashboard answers the following questions:

- Which product category generates the highest sales?
- How do sales change over time?
- Which city generates the highest sales?
- Which products generate the highest sales?

## Key Findings

- Personal Care generated the highest sales among the product categories.
- March had the highest total sales among the three months in the dataset.
- Karachi generated the highest sales among the cities.
- Shampoo was the top product by sales.

## Dashboard Features

- Sales by Product Category
- Sales Trend Over Time
- Sales by City
- Top 5 Products by Sales
- Total Sales KPI
- Date drill-down for analysing sales at a more detailed level
- Top 5 filtering by sales
